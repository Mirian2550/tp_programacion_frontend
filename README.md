# Trabajo Final Integrador — Cuatro Vientos

## Frontend

Temática elegida: **Log de Películas**  
Aplicación web que permite registrar, listar y calificar películas vistas por el usuario.  
Incluye páginas de inicio, listado de películas y formulario para agregar nuevas entradas.
